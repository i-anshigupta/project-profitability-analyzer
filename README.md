# 📊 Project Profitability Analyzer

An interactive **Streamlit dashboard** for analyzing project profitability, ROI, and client performance using financial project data.

---

## 🚀 Features

- 📈 Monthly profit trend visualization
- 🥧 Profit vs Loss distribution
- 🔍 Dynamic filters (Client, Month, Status)
- 📌 Key KPIs:
  - Total Projects
  - Total Profit
  - Average ROI
  - Average Project Duration
- 🏆 Top 5 clients by profit

---
---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Pandas**
- **Matplotlib**
- **Seaborn**
